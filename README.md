## 🚀 Running Locally

This portfolio uses native web technologies without build complexity. You can run it locally with:

### Option 1 — Python
```bash
python -m http.server 4321
```
Open [http://localhost:4321](http://localhost:4321) in your browser.

### Option 2 — Node.js
```bash
npx serve .
```
